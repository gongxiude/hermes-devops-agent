# Jenkinsfile Basics

## Scope

Use this skill for Jenkins Pipeline and Jenkinsfile concepts: declarative pipeline, stages, steps, environment, credentials binding, parameters, and `post`.

## Rules

- Distinguish pipeline definition failures from runtime step failures.
- Treat credentials blocks as sensitive; do not echo or summarize secret values.
- Use stage-level evidence when diagnosing build failures.
- Do not modify Jenkinsfile from a diagnosis skill; draft changes through GitOps/PR workflow.

## Evidence

Based on official Jenkins Pipeline/Jenkinsfile and Pipeline syntax documentation.
